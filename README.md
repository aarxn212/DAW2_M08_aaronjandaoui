
# DAW2 M08 — Aaron Jandaoui

Repositorio de prácticas de Git, GitHub y Markdown del ciclo de Desarrollo de Aplicaciones Web (DAW2).

## Contenido

- `perfil.md`: perfil personal escrito en Markdown.
- `chuleta-git.md`: resumen de los comandos principales de Git.
- `.gitignore`: reglas para ignorar archivos temporales y locales.
- `colaboracion.txt`: archivo utilizado para practicar la resolución de conflictos.
- `index.html`, `style.css` y `script.js`: archivos del portfolio web.

## Objetivos de la práctica

- Trabajar con commits y el historial de versiones.
- Consultar cambios y utilizar el área de preparación.
- Crear ramas y fusionar cambios.
- Resolver un conflicto de Git.
- Utilizar Pull Requests en GitHub.
- Publicar una web estática con GitHub Pages.

## Portfolio

El portfolio se encuentra en la raíz del repositorio y se publicará mediante GitHub Pages cuando la configuración esté completada.
